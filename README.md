# Degraft — Personal Portfolio

A modern personal portfolio website for Degraft, a Computer Science student and aspiring software engineer focused on software development, artificial intelligence, and practical digital solutions.

## Features

- Responsive personal portfolio layout
- Dark professional developer aesthetic
- Sticky navigation with active section highlighting
- Mobile hamburger menu
- Scroll reveal animations and floating hero visuals
- Project filter buttons and modal popup
- Contact form validation with frontend-only placeholder messaging
- Back-to-top button and animated UI details

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## How to Run Locally

### Option 1: Open directly

Open `index.html` in a browser.

### Option 2: Use VS Code Live Server

1. Open the project in VS Code.
2. Install the Live Server extension if it is not already available.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The portfolio will open in your default browser.

## How to Customize

- Update personal content in `index.html`.
- Change colors, spacing, and layout in `css/style.css`.
- Adjust interactions and project data in `js/script.js`.
- Replace placeholder project links and social URLs with real ones when available.
- Replace the placeholder email in the contact section and footer as needed.
